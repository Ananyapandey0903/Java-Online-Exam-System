# Java Online Exam System 📝

A state-managed Java application simulating a timed online examination environment. 

This project was designed to practice Object-Oriented Programming (OOP) principles by modeling real-world entities (Users, Questions, Sessions). It handles user authentication (login/update profile), timer management, session tracking, and automatic score calculation upon submission or timeout.

### 🛠️ Tech Stack
* **Language:** Java
* **Concepts:** Object-Oriented Programming (Encapsulation, Abstraction), Threading (Timers), Collections Framework

### 🧠 Core Learnings
* Managing user session states securely.
* Utilizing `HashMap` or `ArrayList` to store and validate user credentials and question banks.
* Implementing concurrent timer threads to enforce strict session boundaries.
